PIRATE TOKEN BOT
================

ГОТОВЫЙ EXE БЕЗ УСТАНОВКИ PYTHON (через GitHub, бесплатно):
  1. Зайдите на github.com, создайте бесплатный аккаунт и новый репозиторий (New repository).
  2. Нажмите «uploading an existing file» и перетащите в окно ВСЕ файлы и папки из этого архива
     (включая папку .github), затем «Commit changes».
  3. Откройте вкладку Actions: сборка запустится сама и займёт 2-4 минуты.
  4. Откройте завершённую сборку и скачайте PIRATE-TOKEN-BOT-exe: внутри один файл «PIRATE TOKEN BOT.exe».
  Он самодостаточный: звуки и иконки внутри, ни Python, ни cmd, ни билд на своём ПК не нужны.

Как получить один EXE-файл локально:
1. Распакуйте весь архив в одну папку (иконка PIRATE_ICON и звуки должны лежать рядом).
2. Дважды кликните PIRATE_BUILD_EXE.bat и дождитесь надписи ГОТОВО.
   (Если на компьютере нет Python, файл сам попробует его установить — потом запустите его ещё раз.)
3. Рядом появится PIRATE TOKEN BOT.exe. Это один файл: иконка и звуки внутри, консоль не нужна.
   Его можно скопировать куда угодно и запускать двойным кликом. Остальные файлы после сборки не нужны.

Иконка окна, панели задач и шапки меняется вместе с темой: фиолетовая / чёрная / белая.
Иконка самого EXE-файла в проводнике одна (фиолетовая): Windows не умеет менять её на лету.

Окно без рамки: перетаскивается за верхнюю панель, размер меняется за любой край или угол.
В Interface — тема, язык и 9 звуков запуска (при выборе звук проигрывается). При остановке играет звук отключения.
Раздел «Антибан»: во время матча несколько действий идут одновременно и случайно — ходьба (W A S D, в том числе
по диагонали), бег (Shift), прыжок (Пробел), ЛКМ, движение мыши и одна своя клавиша (кнопка рядом с ней).
Ввод идёт через сканкоды, как у реальной клавиатуры. По умолчанию антибан выключен.
Чтобы бот не жал клавиши в лобби/меню: в матче наведи курсор на то, что видно только в матче (например, полоску
здоровья), нажми F11 и включи «Только в матче». Вне матча бот всё отпускает и ждёт.
Раздел «Контроль команды»: бот выходит из матча раньше таймера, только если ВСЕ 4 игрока (включая тебя) погибли.
Для каждого игрока задаётся явный визуальный признак смерти (кнопка «Задать», затем за 4 секунды наведи курсор на него в игре).
Смерть подтверждается 3 проверками подряд на одном кадре; если хоть у одного игрока признак не виден, катка продолжается.
После подтверждения: антибан сразу останавливается, бот выходит в лобби, а затем по обычному алгоритму начинает новый цикл.
Окно преждевременного запуска новой катки можно отметить («Окно запуска»): бот не будет кликать рядом с ним.
Авто-пропуск опроса: пока бот запущен, он сам распознаёт экран «Нам интересно узнать ваше мнение» и нажимает «Пропустить»
(также проверяет экран перед каждым кликом по Play). Отключается галочкой в разделе «Настройки».
Клики бота «живые»: курсор плавно подходит к кнопке, ждёт подсветку и нажимает с удержанием; клик по кнопке выхода из матча
дополнительно проверяется (до 3 попыток), чтобы бот не застревал в меню.
Надпись outmoney слева внизу открывает Telegram-канал.

Запуск без сборки: py -m pip install pyautogui keyboard pillow, затем py PIRATE_TOKEN_BOT.py
